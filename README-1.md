# AI Student Support Assistant

A chatbot that answers students' college questions (registration, attendance, grading, fees, hostel, scholarships, regulations, syllabus) using **semantic retrieval (RAG)** over a 37-document knowledge base. Built with Flask, a vanilla JavaScript frontend, and local embeddings.

## What it does
- Understands questions in the student's own words ("How many days of class can I miss?" finds the Attendance Policy)
- Searches **all 37 documents**: 10 knowledge-base articles, 12 FAQs, 10 regulations, 5 course syllabi
- Returns the best answer, related topics, and **sources with relevance scores**
- Says it cannot help when a question is outside the knowledge base (score threshold)
- Keeps session history through a memory manager
- Falls back to keyword search if the embedding model is unavailable

## How retrieval works
1. Every document is converted to a vector with the `BAAI/bge-small-en-v1.5` embedding model (via `fastembed`, runs on CPU).
2. The student's question is converted to a vector the same way.
3. Cosine similarity ranks the documents; the top 3 above `MIN_SCORE` are returned.
4. The response generator answers from the best match and lists related topics.

I also tested a hybrid score (semantic similarity + keyword overlap). On the evaluation set it gave no gain (80% top-1 at weights 0 to 0.15, 75% above that), so the default is semantic only (`KEYWORD_WEIGHT=0`). The option is kept so it can be re-tested with a larger question set.

## Retrieval quality
Measured with `python evaluate.py` on 20 in-scope and 5 out-of-scope questions (`eval_questions.json`):

| Metric | Result |
|--------|--------|
| Top-1 accuracy | 16 / 20 (80%) |
| Top-3 accuracy | 19 / 20 (95%) |
| Out-of-scope rejected | 5 / 5 |

## API
| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/api/chat` | Ask a question (`session_id`, `message`); returns answer and `sources` |
| GET | `/api/search?q=...` | Search the knowledge base with scores |
| GET | `/api/faq` | All FAQs |
| GET | `/api/regulations` | All regulations |
| GET | `/api/syllabus/<subject>` | Course syllabus |
| GET | `/api/history/<session_id>` | Chat history |
| DELETE | `/api/clear-session/<session_id>` | Clear a session |
| GET | `/health` | Health check |

Example:
```json
POST /api/chat
{ "session_id": "demo", "message": "How many days of class can I miss?" }
```

## Run locally
```bash
python -m venv venv
venv\Scripts\activate        # Windows
pip install -r requirements.txt
python app.py
```
Open http://localhost:5000/static/index.html. The first run downloads the embedding model (about 130 MB).

Copy `.env.example` to `.env` to change settings (`MIN_SCORE`, `PORT`, `DEBUG`).

## Tests
```bash
pip install pytest
python -m pytest -q
```

## Limitations and next steps
- Knowledge base is sample college data stored in JSON files
- Answers are retrieved text, not generated by a language model
- Sessions are stored in memory and reset when the server restarts
- Next: LLM-generated answers grounded in the retrieved documents, and cloud deployment
